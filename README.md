# Netology JSAQA — 7.7 Cypress 2

В репозитории находятся два независимых Cypress-проекта:

- `cinema/` — UI-тесты учебного приложения «Идём в кино» (`https://qamid.tmweb.ru`);
- `petstore-api/` — текущий пример CRUD-тестов для Swagger Petstore.

## Требования

Node.js 18+ и npm.

## Запуск UI-тестов кинотеатра

```bash
cd cinema
npm install
npx cypress run
```

Открыть Cypress в интерактивном режиме:

```bash
npx cypress open
```

UI-тесты проверяют главную страницу, успешную и неуспешную авторизацию, а также бронирование места. Данные и селекторы вынесены в fixtures. В сценарии бронирования название зала читается из админки и сопоставляется с залом, в котором есть доступный сеанс на главной странице.

Учебные учётные данные: `qamid@qamid.ru` / `qamid`.

## ВАЖНО: соответствие API части заданию

В задании 7.7 API-проект должен тестировать приложение из архива по ссылке Яндекс Диска, указанной в условии. Текущая папка `petstore-api/` тестирует Swagger Petstore и **не является выполнением API-части задания 7.7**. Она оставлена как пример CRUD-тестов, чтобы не выдавать неподтверждённые эндпоинты за реальные.

Чтобы заменить пример корректными тестами, нужен JAR-файл из задания (или описание его API: адрес, методы, эндпоинты и JSON-схемы). Без запуска этого приложения нельзя достоверно написать и проверить API-тесты.

## Cypress Dashboard

Dashboard не подключён. Для подключения нужно создать отдельные проекты в Cypress Cloud, добавить выданные `projectId` в конфиги и выполнить запись:

```bash
npx cypress run --record --key "$CYPRESS_RECORD_KEY"
```

Record Key храните в переменной окружения, не добавляйте его в репозиторий. После записи включите публичный доступ и добавьте ссылки на запуски.

**Статус проверки:** исходники UI-тестов исправлены по разметке исходного учебного приложения. Полный запуск Cypress в этой среде не выполнен. Для завершения API-части требуется JAR-файл из условия; Dashboard также требует авторизации в вашем аккаунте Cypress Cloud.
