# Netology JSAQA — 7.7 Cypress 2

В репозитории два независимых Cypress-проекта:

- `cinema/` — UI-тесты приложения «Идём в кино» (`https://qamid.tmweb.ru`);
- `petstore-api/` — API-тесты пользователей Swagger Petstore (`https://petstore.swagger.io/v2`).

## Требования

Node.js 18+ и npm.

## Запуск UI-тестов кинотеатра

```bash
cd cinema
npm install
npx cypress open
# запуск в headless-режиме:
npx cypress run
```

В наборе есть проверки главной страницы, входа администратора (позитивный и негативный сценарии), а также сценарий бронирования. Учётные данные и селекторы вынесены в `cypress/fixtures/`.

Тестовый аккаунт из учебного задания: `qamid@qamid.ru` / `qamid`.

## Запуск API-тестов Petstore

```bash
cd petstore-api
npm install
npx cypress open
# запуск в headless-режиме:
npx cypress run
```

Проверяются создание, изменение и удаление пользователя. Каждый тест самостоятельно создаёт нужные данные, поэтому сценарии не должны зависеть от порядка запуска.

## Cypress Dashboard

Для подключения Dashboard необходимо войти в [Cypress Cloud](https://cloud.cypress.io/), создать проект для соответствующего набора и добавить его `projectId` в файл `cypress.config.js`. Затем запустить запись:

```bash
npx cypress run --record --key "$CYPRESS_RECORD_KEY"
```

Record Key храните в переменной окружения и не добавляйте в репозиторий. После настройки включите публичный доступ к запускам и добавьте ссылки на Dashboard сюда.

**Важно:** Dashboard ещё не привязан к аккаунту, а выполнение тестов в этой среде не подтверждено. Селекторы кинотеатра могут потребовать уточнения при фактическом запуске, если разметка учебного сайта изменилась.
